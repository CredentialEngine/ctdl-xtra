Credential Registry

The University of Arkansas organisation record. Read only. Nothing is ever sent.

→
Step 1 · the only step that goes online
Crawl

Fetches each address once, one request per second. Consults the lookup before every fetch.

Page store (written once)

Exact bytes of every document, named by their digest, each with a sidecar: address, time, status, headers. Plus the address-to-digest lookup.

→
Step 2 · offline, repeatable
Extract

Rule registry → prerequisite parser → language model for what is left → guards → conformance checks. Every value leaves with its evidence and its reasoning.

CTID ledger

Organisation + course code → CTID. Mint once, remember.

Language model cache

Answers kept by model, prompt version and input.

→
Step 3 · static files, no backend
Output

One file per course: the CTDL record plus a provenance entry for each field. Display copies of the source documents. A run report.

Viewer

Source on the left, JSON-LD on the right, “Why this value” beneath it. Read-only.

In this course we study managerial accounting concepts and their use in business decisions. We will examine the development and analysis of cost information for management use in decision-making, income determination, and performance evaluation. Prerequisite: ACCT 20103 with a grade of C or better. (Typically offered: Fall, Spring and Summer)

Rule title-line.credit. The title line of every course block ends with a credit statement. The rule reads the number before “Hour” or “Hours”.

(?P<min>\d+)(?:-(?P<max>\d+))?\s+Hours?\.\s*$

Rule catalog.credit-unit. The title line does not say what kind of hour. The index page does, once, for every course.
