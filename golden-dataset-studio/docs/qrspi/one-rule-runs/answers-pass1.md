| 1 | AI button on sidebar rows: on hover/selected only, or always? | **Hover and selected row only.** |
| 2 | A run whose fix needs another rule changed | **Not separate runs.** Rules that depend on each other (an upstream rule and the rules that read from it) change as **one transaction**: published together in one ruleset version, rolled forward or back together, by the same Claude session. Eric would never accept an upstream change unless he knew the downstream rules still work. Design how. |
| 3 | The "fix every rule" button | **One Claude session for several rules**, not one run per rule (too slow; and changing a set of rules together is the point). Claude may register each rule's work separately. The button gets a **rule picker**: any subset or all; default selection = rules with annotations or some progress. A sidebar run is the same thing with one rule selected. |
| 4 | Runs at once | **Start with 2** (no memory increase on the K2 server). **Validate that the queue really works with K2** and show the exact HTTP requests the Studio makes to K2. |
| 5 | A new ruleset version per publish | **Fine**, as long as publishes are queued so versions can't race. |
| 6 | Course marked wrong, no expected value | **Yes: Claude infers it**, and the report shows what it guessed, in a **structured** form the CLI renders (not Claude's formatting). |
| 7 | At most 3 to-dos; inline quotes with citation; CLI checks quotes | **Yes.** |
| 8 | CLI refuses vague words ("this", "that", "here") in to-do titles | **No: a band-aid.** Fix the root cause: the prompt, the report's structure and how it is rendered, so the report can't depend on context the reader doesn't have. |
| 9 | Save button in the report for "save as the expected value" | **Yes, if it can be made to work.** |
| 10 | Who sees the prompt | **Keep visibility exactly as today.** Adding a button to view the prompt on a finished run's report is fine and useful. |
| new | Context for links | **Dereference what links point to**: show the needed context (the course's value, the page text, the comment) in a readable form right in the report. Exactly what the reader needs, nothing more; use progressive disclosure. Reimagine the report this way. |
