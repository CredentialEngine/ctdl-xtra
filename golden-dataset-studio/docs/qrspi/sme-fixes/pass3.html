Q10.4

From one course to the whole catalog, and finding where it's wrong

"Found" is recall and "right" is precision, under plainer names. The unit is one pair (one duration object). Every golden pair is matched one-to-one with an extracted pair, then each pair gets one outcome. The catalog's numbers are counts of pairs summed over all courses, so a course with 4 durations counts 4 times. Numbers below are illustrative; no duration golden set exists yet.

How the numbers are made
each pair → exact · wrong field (paired, text differs) · missed (golden, no partner) · extra (extracted, no partner)

found (recall) = exact ÷ golden pairs = exact ÷ (exact + wrong + missed)
right (precision) = exact ÷ extracted pairs = exact ÷ (exact + wrong + extra)
courses exact = courses whose whole list is exact ÷ courses

"Not on the page" (a claim) vs "Nothing found" (no claim)

A rule ends one of three ways on a course: it finds a value; it claims the property isn't on the page (it found the place where the property would be, checked it, and it isn't there); or it finds nothing and claims nothing (its selector matched nothing, so the property may still be on the page). Reviewers answer with the same ✓ ✕ as always. The reason flag appears only after ✕.
