Proposed scoringpair, then score fields
1) Pair golden and extracted profiles one-to-one by their description (the same greedy similarity pairing xtra uses). 2) Score each paired field: text by similarity, numbers and ranges by value. 3) An unpaired golden profile counts as missed and an unpaired extracted one as extra. The result: field recall 3/6 (missed fields count against it), profile precision 2/3.
CTDL check: timeRequired holds one ISO 8601 duration (PT54H), never a range. In CTDL, Jared's "timeRequired 54.0 - 432.0" is minimumDuration PT54H + maximumDuration PT432H. A single number such as Lab 432.0 can be exactDuration or timeRequired.
