Q9.1

Why "Annotated by" sometimes comes up empty

The server keeps the 8 most recently used rules in memory. When a 9th is needed, it deletes the oldest. Two people's requests can do that at the same moment, with no lock. This happened once in the available log: 1 of 131 /annotators requests, 2026-11-04 16:26:36Z, KeyError: 'course-keyword'.

Request A (one reviewer)Request B (another, same instant) 0
course-keywordr2r3r4r5r6r7r8
Memory is full. The oldest entry is course-keyword. 1
Needs a rule not in memory. "Full: delete the oldest → course-keyword"
Also needs a new rule. "Full: delete the oldest → course-keyword"
2
Deletes course-keyword. OK.
3
Deletes course-keyword: already gone → KeyError → 500
4
Gets its list of reviewers.
Gets nothing: "Annotated by" is empty until reload.
Fix: a lock, so only one request edits that memory at a time. B waits about a millisecond, then deletes the next-oldest entry.
