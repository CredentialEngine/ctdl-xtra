# Walkthrough: LearningProgram in the Golden Dataset Studio

A 2-minute screen recording of the Studio running locally, with a voiceover. Playwright recorded it on a scratch copy of the
migrated data. That copy has WVU's and AVC's real LearningProgram rules (Phase 7) and Seth's description findings (Phase 6).

- **Voice:** macOS `say` (Samantha).
- **Encoding:** ffmpeg muxed it to H.264 and AAC.
- **Illustrative scores:** the score views use illustrative history, because locally only AVC Course has an extract output.

## Choosing a class (0:00)

The Golden Dataset Studio now covers a second CTDL class: Learning Program. The class menu sits after the catalog. It sets the class for every tab to its right and for the AI button, and the address keeps it. Here, West Virginia University switches from Course to Learning Program.

## LearningProgram Rules and the identifier card (0:18)

These are W.V.U.'s first Learning Program rules: program pages, one record per page, and the External Identifier, Name and Description. The identifier is the code the page prints. Hovering it shows where it was read: here, Minor Code U 1 20. A program that prints no code gets the word program and its name, as every program at Antelope Valley College does.

## An AI run across classes (0:41)

With All classes, the Rules tab has a heading for each class. The AI button offers a run for each class that has rules. Each run is labelled with its class, and all of them wait in one shared queue.

## Records with two pages (0:53)

In Records, one program can come from two pages. Mechanical Engineering is taught at Morgantown and at W.V.U. Tech. Neither page prints a code, so both make one record, and each value says which page it came from.

## The home page, side by side (1:07)

On the home page, the Classes menu puts Course and Learning Program side by side. Required properties come first, then Phase 1, and Phase 2 is folded into one column until you open it.

## Scores, from overview to one property to Evals (1:19)

The x-tra score view shows how x-tra C.L.I.'s output scores against the golden values, for every class and catalog. The numbers here are illustrative, because only one local catalog has an output. A row opens the next level down: one property across catalogs, then one catalog, and from there that catalog's Evals tab.

## Adding a finding and setting a status (1:39)

In Evals, Where it's wrong now has a Finding column. Here we add a finding for a group of wrong values, with a code and a title. Back on the property's page, its findings are listed under the scores. Anyone can mark the property Needs review, and only a subject-matter expert can mark it Done.
